# The Refella visual language

[← Refella](../README.md) · [Landing-page guide](LANDING-PAGE.md)

## Familiar, light, conversational

The repository follows the supplied landing page: a sky-blue hero fading into paper, rounded white surfaces, tightly spaced headlines, and familiar chat bubbles. The original Refella conversation mark is reproduced in the repository hero.

## Shared tokens

| Token | Value | Role |
| --- | --- | --- |
| Sky | `#6aaee2` | Brand color and hero atmosphere |
| Paper | `#f3f3f3` | Quiet background |
| Ink | `#0e0a07` | Primary copy and logo |
| Card | `#ffffff` | Rounded surfaces |
| Incoming bubble | `#f2f2f1 → #ececea` | Business replies |
| Outgoing bubble | `#4ebaff → #0088ff` | Customer messages |
| Card radius | `24px` | Shared landing-page corner treatment |

The landing page uses a rounded system font stack with Inter as a fallback. Repository SVGs use a portable sans-serif stack for reliable rendering without remote font requests.

These are static illustrations of the product vision, not screenshots of working integrations. Essential product details also appear as README text for accessibility and mobile reading.

GitHub controls the surrounding page interface and Markdown typography. The custom SVG artwork supplies the visual identity while standard headings, links, and tables keep the documentation usable in GitHub's light and dark themes.

## Keep the identity consistent

Use generous whitespace, short headlines, soft surfaces, and conversational examples. Keep prices and rewards illustrative unless verified. Link only to confirmed destinations; decorative artwork should not look like a working button.
