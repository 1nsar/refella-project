# Referral Agent

Конфиденциальный основной репозиторий продукта. Не путать с будущим публичным репозиторием хакатона. Название Referral Agent рабочее; бренд не утверждён.

> An AI referral manager that turns customer recommendations into bookings and purchases—all inside messaging apps.

Клиенты общаются с бизнесом в привычном мессенджере: приглашают друзей, уточняют предложение, оформляют заявку или запись и узнают свои бонусы. Приложение нашего продукта клиент не устанавливает. Существующие агенты и системы бизнеса подключаются через API.

## Статус

На 12 сентября 2026 реализован первый локальный MVP: SQL-учёт, API, кабинет владельца и агентские инструменты. Production — назначение репозитория, не подтверждённая готовность продукта. Live-мессенджер, модель и применение схемы к удалённому Supabase ещё требуют доступа и проверки.

## Запуск

Node.js 24. Из корня: `npm ci`, затем заполнить `runtime/.env.local` по `runtime/.env.example` и выполнить `npm run dev`. Кабинет: `/app`. Подробные шаги, настройка тестового бизнеса и список ограничений — [RUNBOOK](docs/RUNBOOK.md).

Проверки: `npm test`, `npm run typecheck`, `npm run build`. Отдельные реальные PostgreSQL-тесты: [DATABASE](docs/DATABASE.md). Секреты, состояние сессий и артефакты сборки не коммитятся.
